# SwipeClean
Swipe right = keep (green), swipe left = trash (red). Trash is a review bin; delete forever from there.

## Build
**Android Studio:** open this folder, let Gradle sync, Run (or Build > Build APK).
**No Android Studio:** push this folder to a GitHub repo. Actions tab > "Build APK" > download the `SwipeClean-apk` artifact.
Requires Android 11+ (minSdk 30).
